# PD Brain Atlas

An interactive atlas of molecular findings from human Parkinson's disease brain tissue, organized by the brain regions where they were measured. The atlas links published findings to their PubMed sources and displays regional imaging effects and pathology staging alongside them.

**Website:** https://soulnature.github.io/PD-Brain-Atlas/

This repository contains the static website generated by Biomni-PD. Open `index.html` directly in a modern browser, or serve this directory with `python3 -m http.server 8000`. Plotly is loaded from its public CDN, so viewing the 3D brain requires an internet connection.

## Explore

- Select a brain region to review its published findings and supporting evidence.
- Search for a molecule to view the reported direction of change across regions.
- Switch between literature coverage, imaging effects and Braak stage-related maps.
- Filter findings and download the selected table as TSV.

## Evidence and sources

The published-literature snapshot contains 776 findings from 405 papers. Evidence sentences are checked against Europe PMC abstracts. A matching sentence establishes its textual source; it does not replace expert verification of the extracted interpretation.

Imaging effects are derived from ENIGMA-PD (Laansma et al., 2021). Braak stage-related region annotations follow Keo et al. (2020). Cortical geometry uses fsaverage5/Desikan-Killiany, and subcortical geometry uses MASSP. Some brain regions have approximate mappings or marker positions. Healthy-brain molecular expression is background context, not PD differential expression. The website provides additional source links and caveats.

Spatial co-location is an association and does not establish a causal mechanism. This resource is for research use.

## Publishing and updates

In this repository, select **Settings → Pages → Deploy from a branch → main → / (root) → Save**. GitHub Pages publishes the static files at the website address above.

To update the website, replace `index.html`, `style.css`, `app.js` and `data.js` with the newly generated files from Biomni-PD's `docs/site/` directory, then commit and push to `main`. Keep `.nojekyll` in the repository root.
